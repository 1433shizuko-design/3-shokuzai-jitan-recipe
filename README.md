# 3食材で！時短ごはん

家にある食材を3つ選ぶと、30分以内に作れる晩ご飯のおかずを探せる日本語Webアプリです。APIキー、外部API、バックエンド、外部データベースは使用していません。

## 主な機能

- 文字入力・候補・カテゴリから食材を3つ選択（候補外の自由入力にも対応）
- 入力食材との一致数と調理時間で並べるレシピ検索（最大5件）
- 材料、分量、工程時間、下準備、コツ、保存方法を含む詳細表示
- 使用する入力食材／使わない入力食材／追加材料／調味料を明確に分けて表示
- お気に入り、前回の食材の再利用、ランダム表示、印刷
- PC・スマートフォン向けレスポンシブ表示

## 食材カテゴリ・レシピ数

肉類、魚介類・加工食品、野菜・きのこ類、卵・大豆製品、缶詰・瓶詰、乾物・常温保存食材、麺類・主食系、その他の8カテゴリです。レシピは **42種類** を収録し、すべて30分以内です。

## ローカルで開く方法

もっとも簡単なのは、`index.html` をダブルクリックしてブラウザで開く方法です。ローカルサーバーで確認する場合は、このフォルダで次を実行します。

```powershell
python -m http.server 8000
```

続いて `http://localhost:8000` をブラウザで開いてください。終了はターミナルで `Ctrl + C` です。

## ディレクトリ構成

```text
index.html                 画面の構造
style.css                  配色・レイアウト・レスポンシブ表示
script.js                  食材選択、検索、詳細、お気に入りの処理
recipes.js                 食材候補と42件のレシピデータ
assets/recipe-mascot.png   提供キャラクター画像（ユーザー配置）
README.md                  この説明書
```

## キャラクター画像の配置

元画像は作業環境に見つからなかったため、代替画像は使用していません。提供画像を `assets` フォルダへコピーし、ファイル名を **`recipe-mascot.png`** にしてください。配置後、ブラウザを再読み込みすると表示されます。画像が未配置の間は、画面上に「キャラクター画像を配置してください」と表示されます。

## ブラウザに保存するデータ

`localStorage` に以下を保存します。

- `jitan-recipe-favorites`：お気に入りのレシピID
- `jitan-recipe-last-ingredients`：前回検索した3食材

ブラウザのサイトデータを削除すると、お気に入りと前回の食材も消えます。レシピ本体はブラウザ保存ではなく `recipes.js` に入っています。
